# SAHAAYA - Mental Wellness Chatbot

## Overview

Sahaaya is a rule-based chatbot developed using Python. It is designed to provide simple emotional support through interactive conversations. The chatbot allows users to perform a daily emotional check-in, receive motivational quotes, and get helpful suggestions based on their mood.

---

## Features

- Personalized welcome using the user's name
- Daily emotional check-in
- Stress support
- Sadness support
- Positive reflection
- Motivational quotes
- Activity suggestions
- Session statistics
- Friendly greetings
- Personalized goodbye message

---

## Technologies Used

- Python
- Random Module
- Functions
- Dictionaries
- Lists
- Conditional Statements
- Loops

---

## How to Run

1. Install Python.
2. Download the project.
3. Open the project in VS Code.
4. Run:

```bash
python Sahaaya.py
```
